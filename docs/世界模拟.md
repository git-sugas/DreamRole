# 世界模拟：让 AI 给你跑一个活着的江湖

> DreamRole 的世界模拟是一个**桌面端 AI 跑团引擎**：你用一句话起一个世界观，LLM 负责生成地图、NPC、势力、任务与叙事，一套确定性的数值引擎负责骰子、战斗、经济与时间流逝。你说人话，它跑世界。

![场景主界面](worldsim-shots/13-scene-intro.png)

*上图：进入世界后的场景主界面——左栏是地点与在场人物，中间是旁白叙事流，右栏是十八个功能入口与「动态」信息流。*

---

## 一、从新建世界开始（5 分钟上手）

### 1. 挑一个题材模板

在「世界模拟」页点击 **+ 新建世界**，先看到世界卡墙和题材模板：

![新建世界](worldsim-shots/02-gen-dialog.png)

内置六套题材模板，一键填表（点模板只填表、不会自动开始生成，改完再点生成）：

| 模板 | 题材 | 你会得到什么风味 |
|---|---|---|
| 仙侠修真 | 灵气、宗门、境界 | 灵田灵矿、坊市、宗门势力 |
| 武侠古代 | 江湖、门派、镖局 | 镖局接镖、黑市拍卖、帮派火并 |
| 西幻中世纪 | 剑与魔法 | 公会委托、地城、领主纷争 |
| 现代都市 | 都市日常 | 写字楼、便利店、都市传说 |
| 科幻未来 | 星际与义体 | 交易所、废料带、能量节点 |
| 末日废土 | 生存与稀缺 | 拾荒、避难所、变异区 |

也可以完全自拟世界观：填前提（比如「我是青石镖局最后的趟子手，接了一趟不许失败的暗镖」）、基调（轻松诙谐 / 严肃暗黑）、魔法与科技水平、世界规模。多选题材标签时，生成器会在候选题材间融合；不选则完全按你的文字描述来。

![填写世界观](worldsim-shots/03-gen-filled.png)

### 2. 看它长出一个世界

点 **开始生成** 后，LLM 分段产出世界观（lore）、NPC、地点、势力、物品、任务与世界书条目，进度实时可见：

![生成进度](worldsim-shots/04-gen-progress.png)

生成完可以先预览再决定要不要——世界观、人物、地点、任务四个页签随便翻：

| 预览 | 内容 |
|---|---|
| ![世界观预览](worldsim-shots/05-preview-lore.png) | 世界观基调、势力关系、时代背景 |
| ![人物预览](worldsim-shots/06-preview-npc.png) | 每个 NPC 的身份、立场、所属势力 |
| ![地点预览](worldsim-shots/07-preview-locations.png) | 聚落与荒野的分布、危险度、连通关系 |
| ![任务预览](worldsim-shots/08-preview-quests.png) | 主线/支线的目标与发布人 |

本次试玩的示例世界「千里孤镖行」（武侠模板 + 一句前提）一次生成了 **10 个 NPC、6 股势力、10 个地点、192 件物品、5 条任务、17 条世界书条目**，全部围绕「押镖」这个核心前提展开，没有跑题串味。

### 3. 捏人：属性与天赋

满意就保存，然后分配属性点、选天赋——属性决定骰子检定的加值，天赋是贯穿全程的被动（采集、砍价、刀法、奇遇……）：

![属性分配](worldsim-shots/09-attribute-alloc.png)

![天赋选择](worldsim-shots/10-talent-select.png)

保存进库。世界卡墙上从此多了一张卡：

![世界保存](worldsim-shots/11-world-saved.png)

点开卡片可以看世界的完整档案（规模、NPC/地点/物品统计）：

![世界详情](worldsim-shots/12-world-detail.png)

## 二、进入世界：回合制的「说人话」跑团

点开世界进入场景视图。你的每一个输入就是一回合：可以说话、可以行动、可以问路、可以砍价——**全部用自然语言**。

### 旁白 + 骰子：叙事之下是硬数值

引擎在 LLM 叙事之下跑一套确定性数值系统：属性、技能、骰子检定、物品、货币。你让角色「采些草药」，引擎真的会掷一次敏捷检定：

![采集检定](worldsim-shots/34-gather-result.png)

*黑松林里采药：敏捷检定 16 ≥ 难度 10 → 拿到黑松露×2、韧皮纤维×1，采集等级 +12 经验。掉落由引擎按物品池结算，不由 LLM 空口编。*

探测机缘这类纯运气事也是明骰：

![探测掷骰](worldsim-shots/43-dicecheck.png)

### NPC 不等你，他们在生活

每推进一回合，世界时间前进一段。NPC 有自己的日程：镖师会在住处歇息，捕快会出城巡视，血手盟的探子会真的从镇上摸进你所在的林子。左栏「在场人物」实时显示每个人**此刻在做什么**，鼠标悬浮还能看到他此刻的念头和今日目标：

![回合推进](worldsim-shots/14-turn1-npc.png)

*试玩中，反派「独眼彪」在我们前往黑松林后自主跟进了林子，下一回合直接图穷匕见拦路——这不是剧本，是 NPC 行为引擎自己走出来的伏击。*

## 三、你能体验到什么

### 🗺️ 地图与旅行（迷雾探索）

世界地图从迷雾开始：蓝框是你所在的地点，绿框是可前往的相邻地点，「?」是未探索的迷雾格。点格子看详情（区域、控制势力、危险度、在场人数），确认后 **前往**：

![世界地图](worldsim-shots/29-world-map.png)

![地点详情](worldsim-shots/30-map-detail.png)

行进本身也是一回合叙事——路上遭遇什么，取决于引擎里的 NPC 分布与随机事件：

![旅途中遭伏](worldsim-shots/31-travel.png)

### ⚔️ 战斗：掷骰战报 + 回合制对话框

野外遭遇敌对 NPC，直接用自然语言应战即可，引擎结算成带数值的战报卡：

![战斗结算](worldsim-shots/35-fight-intent.png)

*「拔刀迎击独眼彪」→ 战报卡：交战双方、威胁度推进、战果与经验。*

主动挑战强敌则进入**回合制战斗对话框**：你与同伴并肩，技能/防御/物品/撤退逐回合操作，敌方单位带小弟与元素属性：

![回合制战斗](worldsim-shots/45-combat.png)

### 🌿 采集 · 🛒 商店 · 💰 经济闭环

荒野地点按题材分布资源点（武侠世界是草药丛/铁矿山/断崖蜜巢，仙侠世界是灵田/灵矿），采集 → 卖钱 → 买装备 → 打更强的怪，闭环成立：

![商店](worldsim-shots/44-shop.png)

### 🐾 生活系统：宠物 · 住宅 · 好友 · 信使 · 据点

- **宠物**：收服与培养战斗伙伴；

- **好友**：与 NPC 处交情，好友会给你透消息、留东西；
- **信使**：托 NPC 给任何地点的人捎信带货，路上要时间、也可能出岔子；
- **据点**：花钱建产业（车马行/货栈/庄园），每回合产出收益，还会遭遇来犯需要守卫。

## 四、建议的体验路线（前 30 分钟）

1. **新建世界**：选一个题材模板 → 补一句自己的前提 → 生成 → 预览 → 满意再保存；
2. **捏人**：属性点堆一条主属性（影响检定），天赋选一条生活线（采集/商贾）+ 一条战斗线；
3. **第一回合**：先「观察四周」摸清所在地，再打开任务日志找主线；
4. **循线探索**：按地图绿格走相邻地点，路上采集、遇敌应战、进聚落逛商店补装备；
5. **安家**：赚到第一笔钱后托信使捎信认识 NPC、看看住宅与据点；
6. **上强度**：等级够高后去城市蹭拍卖会/股市，找秘境入口和世界 Boss 窗口。

## 五、它是怎么工作的（一段话版）

**LLM 负责「讲」，引擎负责「算」。** 世界生成、每回合叙事、NPC 对话由 LLM 产出；但骰子检定、战斗数值、掉落、物价、时间与 NPC 移动全部由确定性引擎结算，LLM 无法凭空送你一件神装。两层之间的契约由严格的输出 schema 与数值范式约束，保证故事再飞，账本不乱。题材差异（资源点、怪物池、建筑画风、采集动词）由六套题材模板统一驱动，同一套引擎跑出六种世界。
